# WEDOS Provider

The WEDOS provider manages DNS zones and records in [WEDOS DNS](https://www.wedos.cz/) through the
[WEDOS HTTP REST API v2](https://kb.wedos.global/api-dns/).

This provider is maintained by [Skip Pay](https://github.com/skip-pay) and is not affiliated with
or endorsed by WEDOS Internet, a.s.

## Authentication

Create an API client in the WEDOS customer administration (HTTP REST API section) with the `wdns`
permission scope. The provider accepts either:

- the client ID and client secret (`client_id`, `client_secret`), from which it requests and
  renews OAuth2 tokens itself, or
- a bearer token generated for the client in the administration (`access_token`).

Prefer the environment variables `WEDOS_CLIENT_ID`, `WEDOS_CLIENT_SECRET` or `WEDOS_ACCESS_TOKEN`
over credentials in configuration. If the API client restricts source IP addresses, run Terraform
from an allowed address.

## Example Usage

```terraform
terraform {
  required_providers {
    wedos = {
      source = "skip-pay/wedos"
    }
  }
}

# Credentials of a WEDOS REST API client with the "wdns" scope. Prefer the
# environment variables WEDOS_CLIENT_ID and WEDOS_CLIENT_SECRET, or
# WEDOS_ACCESS_TOKEN for a token generated in the WEDOS administration.
provider "wedos" {}
```

## Choosing a resource for records

| Resource | Manages | Use when |
| --- | --- | --- |
| `wedos_dns_record_set` | all values of one name and type | records of a zone are managed from several places, or only some records are in Terraform |
| `wedos_dns_records_exclusive` | every record of the zone except the apex NS records | Terraform owns the whole zone; one commit per apply |

Use one style per zone, not both.

## WEDOS behaviour to know

Changes are not atomic and are published by WEDOS in a five-minute cycle; TTL must be between
300 and 172800 seconds; some values are normalised by WEDOS. See the
[WEDOS API behaviour](guides/wedos-api-behaviour) guide before managing production zones.

### Optional

- `access_token` (String, Sensitive) Static bearer token generated in the WEDOS admin, used instead of client credentials. Defaults to WEDOS_ACCESS_TOKEN.
- `base_url` (String) API base URL. Defaults to WEDOS_BASE_URL or https://api.wedos.com.
- `client_id` (String) OAuth2 client ID of the API client. Defaults to WEDOS_CLIENT_ID.
- `client_secret` (String, Sensitive) OAuth2 client secret. Defaults to WEDOS_CLIENT_SECRET.
- `commit` (Boolean) Commit the zone after every resource write (default true). With false, changes are published by the WEDOS autocommit about five minutes after the last change.
- `reload_timeout` (String) How long to wait for the reload, as a Go duration (default 2m). A timeout is reported as a warning: the change is committed and WEDOS reloads it later.
- `wait_for_reload` (Boolean) After each commit, wait until the WEDOS API reports the commit processed (default false). Typically 7–10 s and 3–5 extra API requests per commit. This does not mean the name servers already serve the change: WEDOS publishes in a 5-minute cycle, measured 1–7.5 minutes until all name servers have it. Ignored when commit = false.
